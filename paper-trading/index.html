Comment le bot décide

Tourne chaque jour de bourse via GitHub Actions. Règles fixes, aucune improvisation, aucune donnée cachée.

  1. Récupère l'historique de cours (Yahoo Finance) pour chaque action du watchlist.
  2. Calcule 3 indicateurs par action : ATR% (volatilité), RSI (surachat/survente), et une cassure de plus haut (breakout).
  3. Vend d'abord les positions ouvertes qui touchent un seuil de sortie.
  4. Puis achète, parmi les actions restantes, celles qui passent les 3 filtres d'entrée — en priorisant les plus volatiles.
  5. Met à jour la courbe d'équité et sauvegarde tout dans state.json.
